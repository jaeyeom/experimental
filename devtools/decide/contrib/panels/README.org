#+TITLE: Example decide dashboard panel writers

Example cron scripts for writing external dashboard panels with
~decide panel set~. They are separate from the ~decide~ binary and run
periodically via cron or another scheduler.

* Scripts

** ~tokens.sh~

Writes a ~Chart~ panel (~tokens~) of daily cumulative coding-agent
usage for the current month with a projection to a monthly limit and the
crossing date:

- Reads current subscription usage via ~claude-usage --json~ when
  available.
- Reads the quota projection (~hoursTo100~) via ~quotapace status
  --json~ when available, falling back to the month's daily token pace
  otherwise.
- Reads local Claude Code session logs under
  =$CLAUDE_CONFIG_DIR/projects= (or =~/.claude/projects=) for daily
  token totals.
- Requires ~--limit~ or ~DECIDE_TOKENS_LIMIT~ (there is no default tied
  to any plan).
- Sets ~staleAfter~ to twice ~--interval~ (default ~30m~ -> ~1h~).

Key flags / environment variables:

| Flag / Variable                         | Purpose                                        | Default      |
|-----------------------------------------+------------------------------------------------+--------------|
| ~--limit~ / ~DECIDE_TOKENS_LIMIT~       | Monthly limit (required, positive number)      | (none)       |
| ~--interval~ / ~DECIDE_TOKENS_INTERVAL~ | Cron interval (~staleAfter~ = 2x)              | ~30m~        |
| ~--unit~ / ~DECIDE_TOKENS_UNIT~         | Unit label on chart                            | ~tokens~     |
| ~--profile~ / ~DECIDE_TOKENS_PROFILE~   | ~quotapace~ profile name                       | (all)        |
| ~--quotapace-window~                    | ~quotapace~ window (prefers ~30d~, then ~7d~)  | (auto)       |
| ~--panel-id~ / ~DECIDE_TOKENS_PANEL_ID~ | Target panel id                                | ~tokens~     |
| ~--logs-dir~                            | Override Claude projects directory             | =~/.claude=  |
| ~--dry-run~                             | Print panel JSON instead of calling ~decide~   | false        |

** ~agent-memory.sh~

Writes two panels: a ~Table~ (~agent-memory~) of matching agent
processes (~Name~, ~PID~, ~RSS~) sorted by resident memory descending,
and a ~Gauge~ (~agent-memory-total~) summing their RSS against a
configurable maximum. Works on Linux (=/proc=) and macOS (~ps~).

Key flags / environment variables:

| Flag / Variable                                | Purpose                                    | Default                              |
|------------------------------------------------+--------------------------------------------+--------------------------------------|
| ~--pattern~ / ~DECIDE_AGENT_MEMORY_PATTERN~    | Regex matching process command names       | ~claude/codex/gemini/opencode/aider~ |
| ~--max~ / ~DECIDE_AGENT_MEMORY_MAX~            | Gauge maximum (~8Gi~, ~4096Mi~, etc.)      | ~8Gi~                                |
| ~--warn-pct~ / ~DECIDE_AGENT_MEMORY_WARN_PCT~  | Gauge warn threshold (% of max)            | ~75~                                 |
| ~--fail-pct~ / ~DECIDE_AGENT_MEMORY_FAIL_PCT~  | Gauge fail threshold (% of max)            | ~90~                                 |
| ~--interval~ / ~DECIDE_AGENT_MEMORY_INTERVAL~  | Cron interval (~staleAfter~ = 2x)          | ~1m~                                 |
| ~--match-args~                                 | Match regex against full command arguments | false                                |
| ~--dry-run~                                    | Print panel JSON instead of calling ~decide~ | false                              |

* Crontab examples

Make sure ~PATH~ in crontab includes where ~decide~, ~claude-usage~,
~quotapace~, and ~python3~ are installed (for example =~/go/bin= and
=/opt/homebrew/bin= or =/usr/local/bin=):

#+begin_src sh
  PATH=/usr/local/bin:/opt/homebrew/bin:/home/me/go/bin:/usr/bin:/bin
  DECIDE_TOKENS_LIMIT=50000000

  # Every 30 minutes: update the monthly token usage Chart (staleAfter=1h).
  */30 * * * * /path/to/devtools/decide/contrib/panels/tokens.sh --interval 30m

  # Every minute: update the agent memory Table and Gauge (staleAfter=2m).
  * * * * * /path/to/devtools/decide/contrib/panels/agent-memory.sh --interval 1m --max 16Gi
#+end_src

* Running on a non-hub machine

Panels are stored only on the hub (see [[file:../../docs/panels.org][panels.org]] and
[[file:../../docs/hub.org][hub.org]]). When you run these scripts on a laptop
or worker machine, ~decide panel set~ forwards the panel payload over
SSH (~ssh -T -o BatchMode=yes~) to the hub if hub mode is configured:

1. Configure ~"hub": "me@hub"~ in =~/.config/decide/config.json= (with
   passwordless SSH access and ~decide~ on ~PATH~ on the hub), OR
2. Set ~DECIDE_HUB=me@hub~ in the crontab environment, OR
3. Pass ~--remote me@hub~ (or set ~DECIDE_REMOTE=me@hub~) to either
   script.

When ~--file -~ is used internally, ~decide~ reads the panel JSON on
the local machine and sends it to the hub as ~--data=...~, so no panel
files are created locally.
