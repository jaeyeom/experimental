#+TITLE: decide via and by

~decide show~ prints ~via:~ for an answer. ~decide show --json~ and
~decide list --json~ put it on ~answer.via~. The README states the two
values. This file is the rest of the rule.

* via

- ~ui~ means a person answered in the inbox, or Emacs ran ~decide
  answer --via ui~, or a composer ran ~decide send --id --via ui~.
- ~cli~ means ~decide answer~ or ~decide send --id~ on an open question
  without ~--via~. ~--via cli~ is the same. Any other ~--via~ value is
  an error.

Only the human front ends pass ~--via ui~. Agents do not pass it. A
tool that must act only on an answer given in the inbox or Emacs
checks that ~via~ is ~ui~. An answer stored before ~via~ existed has
no ~via~ in its JSON and does not count as ~ui~. Hub mode forwards
~--via~ unchanged, so an answer from a hub client keeps its ~via~.

This guards against accidents, not a misbehaving agent. Every agent
runs as the same user and can still edit the ledger or drive the TUI.

* by

Each thread message records where it came from.

- ~via~ on a message follows the same ~ui~ or ~cli~ rule for every
  human message: an answer, a composer send, or a new thread from
  ~decide send --to~. Agent messages have none. A message stored
  before ~via~ existed has none and does not count as ~ui~.
- ~by~ is who ran ~decide reply~ or ~decide send --id~: the caller's
  first agentbus name, else the herdr tab label, else the pane handle,
  else nothing. In hub mode the client sends its handle, tab label,
  and agentbus names to the hub, the same way an ask does. ~author~ is
  unchanged. A reply's author is still the thread owner. The inbox
  and Emacs show ~by~ when it is set, and ~author~ otherwise. The
  owner stays in the item header.

~decide show --json~ includes ~via~ and ~by~ on each message, next to
~optionKey~.

A later human free-text message that answers a reopened thread
replaces ~answer~. A tool that needs an earlier option pick reads the
messages. Those keep ~optionKey~, ~via~, ~by~, ~answerType~,
~askingAgent~, and ~askedAt~. ~answer~ keeps only the latest answer's
fields (plus ~answeredAt~).
