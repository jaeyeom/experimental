#+TITLE: decide configuration and keymaps

Config is one JSON object at ~$XDG_CONFIG_HOME/decide/config.json~, or
=~/.config/decide/config.json= when ~XDG_CONFIG_HOME~ is unset. A
missing file is an empty config. Keys you do not set keep the default.
~ui~ and ~web~ are this machine only. A hub does not send them (except
~ui.orgTree~; see [[file:hub.org][hub.org]]).

* Keyboard shortcuts

~ui.keys~ maps action names to lists of keys in config or help notation
(~ctrl+x ctrl+e~, ~C-x C-e~, ~alt+q~, ~enter~, ~shift+tab~, ~j~, ~G~).
A configured action replaces that action's default keys; an empty list
unbinds it; actions not listed keep their defaults. Terminal key
sequences (Ctrl+Enter, ~Alt+q~) and ~DECIDE_KEYDEBUG~ are in
[[file:keys.org][keys.org]].

#+begin_src json
{
  "ui": {
    "keys": {
      "detail.reply": ["r", "R"],
      "edit.external": ["ctrl+x ctrl+e", "ctrl+g"],
      "list.snooze": []
    }
  }
}
#+end_src

Run ~decide keys~ (or ~decide inbox --print-keys~) to print the full
active keymap grouped by view, or ~decide keys --json~ to print it as
JSON ready to copy into ~config.json~. Config loading rejects unknown
action names, unparseable keys, duplicate keys in the same view, and
chord prefixes that are also bound on their own.
