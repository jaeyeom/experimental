#+TITLE: decide Emacs

~devtools/decide/emacs/decide.el~ is a plain Emacs frontend (Emacs 27.1
or newer) that lists, opens, answers, and composes items by calling the
~decide~ CLI. Every command runs directly with an argument list (no
shell), and answers and ~done~ actions record ~via: "ui"~ like
~decide inbox~.

* Setup

Add ~devtools/decide/emacs~ to ~load-path~ and require ~decide~:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/experimental/devtools/decide/emacs")
(require 'decide)
#+end_src

Run ~M-x decide-list~ to open the inbox (~*decide*~), ~M-x decide-compose~
to send a note to a recipient, or ~M-x decide-status~ to open the status
board.

Customizable variables (~M-x customize-group RET decide RET~):

| Variable                       | Default                         | Meaning                                                     |
|--------------------------------+---------------------------------+-------------------------------------------------------------|
| ~decide-program~               | ~"decide"~                      | Name or path of the ~decide~ executable.                    |
| ~decide-herdr-program~         | ~"herdr"~                       | Name or path of the ~herdr~ executable used by ~O~.         |
| ~decide-display-buffer-action~ | ~'(display-buffer-same-window)~ | Display action for the list, open item, and status buffers. |

* Keybindings

** List (~decide-list-mode~)

The list buffer (~*decide*~) calls ~decide list --json~.

| Key         | Action                                                                   |
|-------------+--------------------------------------------------------------------------|
| ~o~ / ~RET~ | Open the item on the current line (~decide show --json~).                |
| ~g~         | Reload the current list (~revert-buffer~ keeps point on the same item).  |
| ~/~         | Filter rows by id, owner, question, or message text; empty clears.       |
| ~c~         | Compose a note to a recipient (~decide targets --json~, ~decide send --to~). |
| ~s~         | Open the status board (~decide status list --json~).                     |
| ~i~         | Switch to the inbox folder (~open~).                                     |
| ~a~         | Switch to the answered folder.                                           |
| ~d~         | Switch to the done folder.                                               |
| ~w~         | Switch to the withdrawn folder.                                          |
| ~q~         | Quit the window.                                                         |

** Item (~decide-item-mode~)

An open item buffer (~*decide <id>*~) shows aligned headers, the thread
with wrapped lines, and numbered options.

| Key       | Action                                                                      |
|-----------+-----------------------------------------------------------------------------|
| ~1~-~9~   | Answer with that numbered option.                                           |
| ~o~       | Answer with an option key via completion.                                   |
| ~0~       | Open a buffer for a free-text reply (~decide-reply-mode~).                  |
| ~y~       | Archive a notification (~decide done --via ui <id> archived~). Items with options still require an answer. |
| ~n~ / ~p~ | Select the next or previous message in the thread.                          |
| ~l~       | Open the item's link with ~browse-url~, or pick from a numbered list.       |
| ~O~       | Focus the owner's herdr tab (~herdr workspace focus~ / ~herdr tab focus~).  |
| ~A~       | Set the owner's avatar (~decide avatars set~).                              |
| ~g~       | Reload the item (~revert-buffer~), looking up the owner location again.     |
| ~q~       | Quit the window.                                                            |

** Answer, reply, and compose buffers

~decide-answer-mode~, ~decide-reply-mode~, and ~decide-compose-mode~
derive from ~text-mode~:

| Key       | Action                                |
|-----------+---------------------------------------|
| ~C-c C-c~ | Send the buffer.                      |
| ~C-c C-k~ | Close the buffer without sending.     |

** Status (~decide-status-mode~)

The status buffer (~*decide status*~) renders agent and resource tables
from ~decide status list --json~ and refreshes every two seconds while
visible.

| Key | Action                |
|-----+-----------------------|
| ~g~ | Refresh immediately.  |
| ~q~ | Quit the window.      |

** Evil

When ~evil~ is loaded, ~decide-list-mode~, ~decide-item-mode~, and
~decide-status-mode~ start in normal state with ~j~ / ~k~ movement,
~g r~ to revert, and ~g i~, ~g a~, ~g d~, ~g w~, ~g s~ folder chords.
~decide-answer-mode~, ~decide-reply-mode~, and ~decide-compose-mode~
start in insert state (or hybrid state when ~evil-default-state~ is
~hybrid~).

* Hub mode

Each action runs one ~decide~ command, so hub mode works automatically
when ~hub~ is set in ~config.json~ or ~DECIDE_HUB~ is set in Emacs's
environment.

To use a hub only in Emacs without changing the global config or
environment, create an executable wrapper script:

#+begin_src sh
#!/bin/sh
exec decide --remote me@hub "$@"
#+end_src

and point ~decide-program~ at it:

#+begin_src emacs-lisp
(setq decide-program "/path/to/decide-hub")
#+end_src
