# repo-sync

`repo-sync` synchronizes project-specific files across multiple development machines using Git-based workflow automation.

Common commands:
- `repo-sync init` — initialize repository sync.
- `repo-sync sync` — synchronize configured projects.
- `repo-sync status` — show synchronization status.
- `repo-sync config` — manage configured projects.
