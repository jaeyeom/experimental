#+TITLE: prsync
#+DATE: 2026-09-10

* Overview

~prsync~ is a JSON CLI that surveys *your* open GitHub PRs, matches each
to a local [[https://herdr.dev/][herdr]] agent tab, and — when you ask — sends that agent a
prompt or posts a GitHub comment.

| Command | What it does |
|---------+--------------|
| ~scan~ | List open PRs (including drafts), bucket which still need you, match each to a herdr tab |
| ~dispatch~ | Send that tab a prompt: review comments (default), rebase (~--rebase~), or red CI (~--ci-fix~) |
| ~comment~ | Post a conversation-level PR comment via ~gh~ (no herdr tab, no gate) |
| ~tabs --orphans~ | Flag live-agent tabs whose PR already merged; ~--close-merged --go~ closes them |
| ~gate~ | One-shot "is an agent busy?" |
| ~logs~ / ~version~ | Dump the run log / print version |

Dry-run by default (~--go~ actually sends or closes). Uses the
already-authenticated ~gh~ CLI and herdr ≥ 0.8; never embeds a GitHub
token. Dispatch is one agent at a time. All commands emit JSON on
stdout.

Typical loop:

#+BEGIN_SRC bash
prsync scan --config ./prsync.config
prsync dispatch --config ./prsync.config          # review rendered_prompt
prsync dispatch --config ./prsync.config --go     # send
prsync tabs --orphans --close-merged --config ./prsync.config
prsync tabs --orphans --close-merged --go --config ./prsync.config
#+END_SRC

Related tracker: [[https://github.com/jaeyeom/experimental/issues/211][#211]].

* Installation

#+BEGIN_SRC bash

#+END_SRC

Or with Bazel from this repo:

#+BEGIN_SRC bash
bazel run //devtools/prsync/cmd/prsync -- version
#+END_SRC

After ~go install~, put ~$GOPATH/bin~ / ~$GOBIN~ on ~PATH~.

* Prerequisites

- ~gh~ authenticated (~gh auth login~). ~prsync~ never calls ~gh auth token~.
- herdr ≥ 0.8 on ~PATH~ for matching and dispatch:
  - missing: ~scan~ degrades (tabs unset); ~dispatch~ and ~gate~ exit 3;
    ~comment~ still runs
  - present but older than 0.8, or unparseable ~herdr --version~: every
    command that would talk to herdr (including ~scan~) exits 3
  - ~comment --stdin~ never talks to herdr
- Linux or macOS. No Windows requirement.

Optional: copy [[file:prsync.config.example][prsync.config.example]] to ~./prsync.config~ or
=$HOME/.config/prsync/prsync.config= and edit.

* Commands

#+BEGIN_EXAMPLE
prsync scan     [--config PATH] [--repo owner/repo ...] [--json]
prsync tabs     --orphans [--config PATH] [--json] [--stdin] [--close-merged] [--go] [--force]
prsync dispatch [--config PATH] [--pr owner/repo#N ...] [--all] [--go] [--rebase] [--ci-fix] [--hint TEXT] [--force] [--stdin]
prsync comment  [--config PATH] [--pr owner/repo#N ...] [--all] [--go] [--stdin] [--allow-duplicate] --body TEXT
prsync gate     [--config PATH]
prsync logs     [--path]
prsync version
#+END_EXAMPLE

| Flag | Commands | Effect |
|------+----------+--------|
| ~--log-level LEVEL~ | all except ~logs~ | ~debug~ / ~info~ / ~warn~ / ~error~. Default ~info~. Also ~PRSYNC_LOG~. JSONL under =$XDG_STATE_HOME/prsync/=; stdout is unchanged |
| ~--config PATH~ | scan, tabs, dispatch, comment, gate | Use this file (must exist) |
| ~--repo owner/repo~ | scan | Repeatable; replaces ~repos~ entirely |
| ~--json~ | scan, tabs | Accepted no-op (stdout is always JSON) |
| ~--orphans~ | tabs | Required; report live-agent tabs with no open/draft PR |
| ~--close-merged~ | tabs | Close ~merged~-bucket orphan tabs (default is dry-run) |
| ~--pr owner/repo#N~ | dispatch, comment | Repeatable; limit candidates |
| ~--all~ | dispatch, comment | Every PR in the scan document (default when no ~--pr~) |
| ~--go~ | dispatch, comment, tabs | Live send / close (default is dry-run) |
| ~--rebase~ | dispatch | Rebase-in-place prompt; skips the unaddressed-comment gate |
| ~--ci-fix~ | dispatch | CI-fix prompt; skips the unaddressed-comment gate. Mutually exclusive with ~--rebase~ |
| ~--hint TEXT~ | dispatch | Non-authoritative CI failure hint (requires ~--ci-fix~). The agent must verify it |
| ~--force~ | dispatch, tabs | dispatch: re-dispatch even if dedupe would skip. tabs: allow ~--close-merged~ when every orphan is ~no_pr~ or ~unknown~ |
| ~--stdin~ | tabs, dispatch, comment | Read a scan document from a pipe or redirected file. Default is self-scan (tabs: self-resolve) |
| ~--body TEXT~ | comment | Comment body to post (required) |
| ~--allow-duplicate~ | comment | Post even if the same ~(repo, number, head_sha, body)~ was already recorded |
| ~--path~ | logs | Print the run-log file path as JSON instead of dumping the file |

Usage errors (exit 2): ~--pr~ with ~--all~; ~--ci-fix~ with ~--rebase~;
~--hint~ without ~--ci-fix~; ~--go~ on ~tabs~ without ~--close-merged~.

~--go~ always sends (or, with ~--close-merged~, closes). ~dry_run=false~
in the config also sends / closes without ~--go~ (for cron); ~tabs~
still needs ~--close-merged~ to close anything.

~--stdin~ reads a scan document only from a FIFO or regular file (a
pipe or redirected file). Sockets, TTYs, and other non-file stdin are
ignored so they cannot hang. Decode errors are fatal. Without
~--stdin~, ~dispatch~ / ~comment~ always self-scan.

#+BEGIN_SRC bash
prsync scan --config ./prsync.config | prsync dispatch --stdin --config ./prsync.config
prsync scan --config ./prsync.config | prsync comment --stdin --body "please retry" --config ./prsync.config
#+END_SRC

* Configuration

Search order (first existing file wins):

1. ~--config PATH~ (missing file → exit 2)
2. ~./prsync.config~ (cwd; honors ~BUILD_WORKING_DIRECTORY~ under ~bazel run~)
3. =$HOME/.config/prsync/prsync.config=

If none exist, built-in defaults are used. That is not an error.

The file is ~KEY=VALUE~, one assignment per line. Blank lines and ~#~
comment lines are ignored. Inline comments (~key=value # comment~) are
not supported. Unknown keys are ignored. The parser does not ~source~
the file.

~*_ms~ keys are integers in milliseconds (~2000~ is 2s, not 2µs).
~true~ / ~false~ / ~1~ / ~0~ are accepted for booleans. ~state_file~,
~gh_bin~, ~herdr_bin~, and ~@/path~ prompt files expand a leading tilde.
Environment variables are not expanded.

** Keys

| Key | Default | Notes |
|-----+---------+-------|
| ~repos~ | empty | Space-separated ~owner/repo~. Empty = auto-discover from open PRs. |
| ~author~ | empty | GitHub login. Empty = ~gh api user --jq .login~. |
| ~title_id_pattern~ | ~[A-Z]+-[0-9]+~ | First match in the PR title is the identifier. |
| ~tab_label_template~ | ~{id}~ | Herdr tab label after substituting ~{id}~. Exact, case-sensitive. |
| ~herdr_bin~ | ~herdr~ | herdr executable. |
| ~gh_bin~ | ~gh~ | gh executable. |
| ~concurrency_wait_on~ | ~any~ | ~any~ = every working or blocked agent; ~managed~ = tabs matched in this scan (~managed~ runs a scan). |
| ~gate_poll_ms~ | ~2000~ | Poll interval for the concurrency gate and post-send settle. |
| ~gate_timeout_ms~ | ~1800000~ | Live dispatch gives up waiting on the gate after this many ms (~gate_timeout~, exit 4). |
| ~dispatch_timeout_ms~ | ~1800000~ | Bound for ~herdr agent prompt --wait~ (and leftover ~herdr agent wait~). Still ~working~/~blocked~ → ~dispatched_timeout~ (exit 4). |
| ~dispatch_prompt_template~ | built-in | Inline text, or ~@/path/to/file~. Substituted: ~{identifier}~ ~{number}~ ~{title}~ ~{repo}~ ~{url}~ ~{head}~ ~{base}~ ~{comments}~. Unknown placeholders are left literal. |
| ~rebase_prompt_template~ | built-in | Same substitution. Used only with ~dispatch --rebase~. |
| ~ci_fix_prompt_template~ | built-in | Same substitution, plus ~{hint}~. Used only with ~dispatch --ci-fix~. |
| ~dispatch_include_drafts~ | ~false~ | When true, ~dispatch~ may send to draft PRs. ~scan~ always includes drafts. |
| ~dispatch_wait_until~ | ~idle done~ | Whitespace-separated settle tokens, passed as ~herdr agent prompt --until~. At least one required. |
| ~state_file~ | =$HOME/.config/prsync/state.json= | Dispatch audit / dedupe log. Written only on live ~dispatched~ / ~dispatched_timeout~. |
| ~dry_run~ | ~true~ | ~--go~ overrides to live. |
| ~comment_link_max_chars~ | ~500~ | Rewrite ~[label](url)~ to ~label~ when ~len(url)~ exceeds this. ~0~ disables. Length only, not host. |
| ~comment_body_max_chars~ | ~4000~ | Cap each comment body after link stripping. Appends ~… [truncated, see <thread url>]~. ~0~ disables. |

Default prompt text (checkout ~{head}~, mechanical vs judgment-call
triage, re-request reviewers, rebase / CI-fix wording) is commented in
[[file:prsync.config.example][prsync.config.example]].

** Live dispatch

~dispatch --go~ does three things, one PR at a time:

1. *Gate* — wait until no waited-on agent is ~working~ or ~blocked~.
   A single idle sample is not enough (startup / mid-run flap still
   counts as busy). A ~blocked~ tab (awaiting you) is waited on like
   ~working~; stderr names it, e.g. ~waiting on w2:tC — blocked
   awaiting your input~. If it still holds at ~gate_timeout_ms~, the
   current PR is ~gate_timeout~ and the rest are ~queued~ (exit 4, no
   prompt, no state write).
2. *Send* — ~herdr agent prompt <pane_id> <prompt> --wait --until idle
   --until done --timeout …~ (tokens from ~dispatch_wait_until~). From
   a non-~working~ pane, herdr must observe ~working~ or ~blocked~
   within five seconds (~agent_prompt_stalled~ otherwise). Pre-send
   ~idle~/~done~ does not complete the wait.
3. *Settle* — debounce-poll ~agent list~ until ~idle~/~done~ holds for
   several consecutive samples. A transient ~idle~ after you answer a
   ~blocked~ question is not completion. If the tab is still
   ~working~/~blocked~, continue with ~herdr agent wait~ using remaining
   ~dispatch_timeout_ms~. ~agent wait~ is never started from a *stable*
   ~idle~/~done~.

If the agent never picks up the prompt, or a wait expires while the tab
is still ~working~/~blocked~, the result is ~dispatched_timeout~ (exit
4; state is written so it is not retried blindly).
~dispatched_blocked~ happens only when ~blocked~ is in
~dispatch_wait_until~ *and* that status holds for the settle debounce:
the batch stops, but dedupe state is not written, so a re-run can
retry. Set ~dispatch_wait_until=idle~ only if you want to wait until
herdr reports ~idle~ (can take ~30 minutes if the agent settles to
~done~ instead).

~prsync gate~ is the same busy-set check without debounce — a snapshot,
not the wait ~dispatch --go~ uses.

** tabs --orphans

Inverse of ~scan~: walk *this machine's* herdr tabs and flag those with
a live agent (~working~ / ~idle~ / ~blocked~) but no open or draft PR.
Usually the PR already merged — the tab, worktree, and gate slot can
be reclaimed.

Tabs whose labels yield tickets via ~title_id_pattern~ are resolved to
the author's PRs (any state) and bucketed:

| Bucket | Meaning |
|--------+---------|
| ~merged~ | Ticket's PR is merged or closed → *safe to close*. ~pr~ has number, repo, ~state~, ~merged_at~ (null if closed but unmerged) |
| ~no_pr~ | Search found nothing, agent is ~idle~ or ~blocked~ → *verify* (may be unpushed WIP). A ~working~ agent with no PR is omitted, not an orphan |
| ~unknown~ | A search chunk matched *no* ticket (broken or throttled sweep, not N genuine ~no_pr~). A ~warnings~ entry is emitted; ~working~ agents are still surfaced |

Skipped: tabs with an open/draft PR, agent-less scratch tabs, unparseable / non-ticket labels.

#+BEGIN_SRC bash
prsync tabs --orphans --config ./prsync.config
#+END_SRC

~--close-merged~ closes only the ~merged~ bucket (dry-run by default;
~--go~ actually closes). ~no_pr~ and ~unknown~ are never touched. If
every orphan is ~no_pr~, or any is ~unknown~, the close refuses
(exit 3) instead of a silent "nothing to close"; ~--force~ overrides.
Each candidate is re-verified at close time so a race cannot close a
tab that grew a new open PR. Only the local herdr socket is visible.

#+BEGIN_SRC bash
prsync tabs --orphans --close-merged --config ./prsync.config
prsync tabs --orphans --close-merged --go --config ./prsync.config
#+END_SRC

#+BEGIN_SRC json
{
  "generated_at": "2026-01-01T09:00:00Z",
  "dry_run": true,
  "results": [
    {
      "tab_id": "w2:tA",
      "workspace_id": "w2",
      "ticket": "AP-1306",
      "action": "would_close",
      "pr": {
        "repo": "acme/widgets",
        "number": 32347,
        "url": "https://github.com/acme/widgets/pull/32347",
        "state": "merged",
        "merged_at": "2026-08-18T22:19:28Z"
      }
    }
  ],
  "warnings": []

Live ~action~ values: ~closed~, ~skipped_not_merged~,
~skipped_not_found~. Dry-run emits ~would_close~.

Pipe a ~scan~ document with ~--stdin~ to reuse its open-PR↔tab matches
(tabs that already have an open PR are skipped without a ~gh search~):

#+BEGIN_SRC bash
prsync scan --config ./prsync.config | prsync tabs --orphans --stdin --config ./prsync.config
#+END_SRC

Missing / unreachable / too-old herdr is a precondition failure
(exit 3), since tabs are the whole input — unlike ~scan~, which
degrades.

** dispatch

Dry-run (default). Review ~rendered_prompt~ and confirm ~pane_id~ is a
pane (~w2:pC~), not a tab id (~w2:tC~):

#+BEGIN_SRC bash
prsync dispatch --config ./prsync.config
prsync dispatch --config ./prsync.config --pr acme/widgets#123
#+END_SRC

#+BEGIN_SRC json
{
  "generated_at": "2026-01-01T09:00:00Z",
  "dry_run": true,
  "results": [
    {
      "repo": "acme/widgets",
      "number": 123,
      "action": "would_dispatch",
      "pane_id": "w2:pC",
      "rendered_prompt": "Get onto this PR's branch before editing: ... Address the unresolved review comments on PR #123 ..."
    }
  ]
}
#+END_SRC

Live send (~--go~) writes ~state_file~ on ~dispatched~ /
~dispatched_timeout~. Gate / serial / wait: [[*Live dispatch][Live dispatch]].
A second live run against the same unaddressed comment ids is
~skipped_deduped~. The prompt always goes to the PR's existing herdr
tab (no new worktree).

| Mode | Flag | Done when | Notes |
|------+------+-----------+-------|
| comments (default) | (none) | listed threads addressed | Dedupe on unaddressed comment ids |
| rebase | ~--rebase~ | not ~BEHIND~ or ~DIRTY~ | Same ~head_sha~ does not block retry of a failed rebase. ~--all~ sends to every PR with a ready tab (auto-picking behind PRs is a follow-up). Missing ~merge_state_status~ in a scan document keeps head-SHA dedupe |
| CI-fix | ~--ci-fix~ | ~ci_state~ no longer ~failing~ | Same ~head_sha~ does not block retry of a still-red check. ~--hint~ is a starting point the agent must verify; omit it to investigate from scratch. Caller chooses ~--ci-fix~ — ~prsync~ does not triage. Missing ~ci_state~ keeps head-SHA dedupe |

Cannot combine ~--rebase~ and ~--ci-fix~; rebase first, then CI-fix. If
you also re-trigger CI, do that last (a new commit invalidates it).
~--force~ re-dispatches even when dedupe would skip. A completed
rebase or CI-fix (satisfied, with a recorded dispatch) is
~skipped_deduped~.

#+BEGIN_SRC bash
prsync dispatch --config ./prsync.config --rebase --pr acme/widgets#123 --go
prsync dispatch --config ./prsync.config --ci-fix --pr acme/widgets#123 \
  --hint 'job X failed at step/target Y; key error: boom; looks real (not flake)'
prsync dispatch --config ./prsync.config --ci-fix --pr acme/widgets#123 --go --force
#+END_SRC

** comment

Posts a PR comment through ~gh pr comment~. No herdr tab, no agent, no
gate — a ~tab~ of ~null~ is not a skip, so this works for off-machine
PRs. Dry-run by default. ~--body~ is posted as-is. JSON matches the
~dispatch~ result shape (~would_dispatch~ / ~dispatched~ /
~skipped_not_found~ / ~skipped_deduped~), with the body in
~rendered_prompt~.

Live send (~--go~) records ~state_file~ on ~dispatched~, keyed on
~(repo, number, head_sha, body)~. The same tuple is ~skipped_deduped~
(including dry-run). A new ~head_sha~ allows the same body again.
~--allow-duplicate~ posts anyway. Comment state does not clobber
dispatch comment-id / rebase / CI-fix fields.

#+BEGIN_SRC bash
prsync comment --config ./prsync.config --pr acme/widgets#123 --body "please retry"
prsync comment --config ./prsync.config --pr acme/widgets#123 --body "please retry" --go
# same head SHA + body: skipped_deduped
prsync comment --config ./prsync.config --pr acme/widgets#123 --body "please retry" --go
prsync comment --config ./prsync.config --pr acme/widgets#123 --body "please retry" --go --allow-duplicate
prsync comment --config ./prsync.config --all --body "please retry"
#+END_SRC

#+BEGIN_SRC json
{
  "generated_at": "2026-01-01T09:00:00Z",
  "dry_run": true,
  "results": [
    {
      "repo": "acme/widgets",
      "number": 123,
      "action": "would_dispatch",
      "rendered_prompt": "please retry"
    }
  ]
}
#+END_SRC

** gate

One-shot busy-set check (no debounce). ~dispatch --go~ uses the
debounced wait described under [[*Live dispatch][Live dispatch]].

#+BEGIN_SRC bash
prsync gate --config ./prsync.config
#+END_SRC

Safe:

#+BEGIN_SRC json
{
  "safe": true,
  "busy": []
}
#+END_SRC

Unsafe (exit 1) when a working or blocked agent is in the busy set.
~agent_status~ distinguishes ~working~ (making progress) from ~blocked~
(awaiting human input):

#+BEGIN_SRC json
{
  "safe": false,
  "busy": [
    {
      "pane_id": "w2:pC",
      "tab_id": "w2:tC",
      "agent_status": "blocked"
    }
  ]
}
#+END_SRC

Self-exclusion uses ~HERDR_PANE_ID~ only. If that env var is empty,
~gate~ does not call ~herdr pane current~ (that would drop the focused
pane under cron).

** logs

Each run (except ~logs~ itself) appends JSON lines to
=$XDG_STATE_HOME/prsync/prsync.jsonl= (or
=~/.local/state/prsync/prsync.jsonl=). Rotates by size (~10 MiB~) and
age (~14 days~). Default level ~info~; stdout JSON is unchanged.
~--log-level~ overrides ~PRSYNC_LOG~.

A dispatch line of investigation includes the target pane, send, each
~agent_status~ transition, gate wait, settle decision, skip/dedupe
outcome, and process exit. Startup records the resolved config path
and ~concurrency_wait_on~.

#+BEGIN_SRC bash
prsync logs --path
prsync logs
#+END_SRC

~--path~ prints ~{"path":"…"}~. Without it, ~logs~ dumps the JSONL file
(empty stdout if no log exists yet).

* Manual smoke test

Against a real herdr ≥ 0.8 and an authenticated ~gh~, run the typical
loop from the overview plus:

#+BEGIN_SRC bash
prsync dispatch --config ./prsync.config --ci-fix
prsync comment --config ./prsync.config --body "please retry"
prsync comment --config ./prsync.config --body "please retry" --go
prsync gate --config ./prsync.config
prsync logs --path
prsync logs
#+END_SRC

Confirm ~agent prompt~ targets a ~pane_id~ (~w2:pC~, not a tab id) and
the default wait is ~--wait --until idle --until done~. README-only;
CI uses fixture binaries, not live herdr.

* Security

- ~prsync~ never calls ~gh auth token~ and never prints the
  environment. Auth is the operator's existing ~gh~ login plus the
  local herdr socket.
- ~comment --go~ posts the given body as a GitHub PR comment. Dry-run
  first; there is no extra confirmation beyond ~--go~.
- ~tabs --orphans --close-merged --go~ runs ~herdr tab close~ on each
  tab still in the ~merged~ bucket. Dry-run first; ~no_pr~, ~unknown~,
  and ~has_open_pr~ tabs are never candidates. An all-~no_pr~ or
  ~unknown~ classification refuses the close unless ~--force~.
- Review comment bodies are interpolated into the dispatch prompt as
  text. ~prsync~ does not execute them. The *agent* may follow
  malicious review text — this is inherent to the product. Do not treat
  the prompt as sanitized English.
- The config parser does not ~source~ the file, so values cannot
  execute as shell.
- JSON on stdout can contain review bodies and logins. That is the
  operator's responsibility.
- Concurrent ~prsync dispatch --go~ across machines sharing
  ~state_file~ over NFS is unsupported.

* Exit codes

| Code | Meaning |
|------+---------|
|    0 | Success |
|    1 | ~gate~ only: busy set is non-empty |
|    2 | Usage, config, or flag error |
|    3 | Missing tool, auth failure, herdr too old, or mid-loop dispatch failure |
|    4 | Live dispatch timed out waiting on the gate or settle |
