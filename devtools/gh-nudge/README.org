* Graduated commands

Most of the =gh-nudge= suite (=gh-nudge=, =gh-slack=, =gh-approve=,
=gh-merge=, =gh-codeowners=, =gh-throttle=, and =gh-storage=) has
graduated to [[https://github.com/chorong-sh/chorong/tree/main/gh-nudge][chorong-sh/chorong]]
(Homebrew formulas in [[https://github.com/chorong-sh/homebrew-tap][chorong-sh/homebrew-tap]]).

~gh-pr-review~ remains in this directory until its remaining work completes:

| Command        | What it does                                              | Docs                                                        |
|----------------+-----------------------------------------------------------+-------------------------------------------------------------|
| ~gh-pr-review~ | Draft line comments locally, then post them as one review | [[file:pr-review.org][pr-review.org]], [[file:cmd/gh-pr-review/README.md][README.md]] |

* Install

Requires ~gh auth login~. From a checkout of this repository, ~make install~
installs ~gh-pr-review~ (~INSTALL_CMDS~ in the root Makefile). From the Go
module proxy:

#+begin_src sh
go install "github.com/jaeyeom/experimental/devtools/gh-nudge/cmd/gh-pr-review@latest"
#+end_src

* Configuration

~gh-pr-review~ reads =~/.config/gh-nudge/config.pkl= when that file exists,
and ~config.yaml~ otherwise (~--config~ overrides the path). Key optional
settings such as ~rerequest.exclude_reviewers~ are documented in
[[file:cmd/gh-pr-review/README.md][cmd/gh-pr-review/README.md]]. The full
schema lives in [[file:pkl/Config.pkl][Config.pkl]] and
[[file:pkl/example.config.pkl][example.config.pkl]].

Go configuration structs in ~internal/config/pkl/~ are generated from
~pkl/Config.pkl~ via the repo-root ~PklProject~ using ~make -C devtools/gh-nudge generate-pkl~
(or ~make generate-pkl~ at the repo root).

* Sharing GitHub rate limits

The shared GitHub CLI client (~internal/github~) invokes ~$GH_BIN~ wherever
it would invoke ~gh~ (defaulting to ~gh~ on ~PATH~). Point ~GH_BIN=gh-throttle~
(installed from [[https://github.com/chorong-sh/chorong/blob/main/gh-nudge/gh-throttle.md][chorong-sh/chorong]])
to share one rate-limit queue across ~gh-pr-review~ and other ~gh~ calls.

* Development

~gh-pr-review~ implements the standard ~toolcli~ protocol subcommands
(=github.com/chorong-sh/chorong/pkg/toolcli=): ~version [--json]~,
~update [--check] [--ref <ref>] [--json]~, ~doctor [--json] [--offline]~,
and ~skill [install|uninstall|status ...]~.

From the repository root, run ~make check~.
