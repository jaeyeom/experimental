* Overview

Small command-line tools I use day to day, mostly in Go. They fall
into three groups: code-quality helpers you can use in any repo
(devcheck, docsync, linters), GitHub and Jira helpers (gh-nudge,
gh-ask, gh-outbox, rename-jira-keys, reviewpush), and a stack for running
several coding agents side by side in [[https://herdr.dev/][herdr]] terminal panes
(agentbus, decide, slackwatch, prsync, orgctl, claude-usage). Each
tool has its own README. Start with the one-line summaries below.

=make install=, from the repository root, installs every package named
by =INSTALL_CMDS= in the root Makefile. That list is the source of
truth, including =gh-approve=, =gh-throttle=, and the three linter
commands (=org-lint=, =pkgvar=, and
=unnecessary-interface-assertion-linter=). =./ensure.sh= is
=devtools/setup-dev/ansible/ensure.sh=. The agentbus daemon is a
second binary: =go install ./devtools/agentbus/cmd/agentbusd=.
fork-keeper is a shell script and has no README.

* Agent workflow
:PROPERTIES:
:CUSTOM_ID: agent-workflow
:END:

[[https://herdr.dev/][herdr]] is the terminal multiplexer. One pane holds one coding
agent. The other tools hang off those panes:

#+BEGIN_EXAMPLE
herdr panes
    |
    +-- agentbus    agents message each other
    +-- decide      you answer and approve
    +-- slackwatch  Slack replies in, approved drafts out
    +-- prsync      one agent tab per open pull request
    +-- orgctl      the written description of the team
#+END_EXAMPLE

agentbus is the bus. It is not the user's approval. decide is the
inbox for questions and approvals. slackwatch delivers Slack replies
to the agent that owns the post, and posts a draft only after decide
has approved it. prsync keeps a herdr tab lined up with each open
pull request. orgctl checks a declarative team spec against the live
tabs, names, and scheduled jobs. claude-usage only reports rate-limit
windows. After a reboot, follow
[[file:agentbus/reboot.org][the agentbus runbook]].

* Installation
:PROPERTIES:
:CUSTOM_ID: installation
:END:

** Prerequisites

- *Go 1.26+*, matching the =go= line in the root =go.mod=.
- *Git*.
- *Bazel*, for ascii-art and repo-sync.
- *Emacs*, for org-lint and the magit command.
- *GitHub CLI (gh)*, for the gh-nudge commands.
- *Ansible*, for setup-dev.

** gh-nudge commands

=devtools/gh-nudge/cmd/= holds =gh-approve=, =gh-codeowners=,
=gh-merge=, =gh-nudge=, =gh-pr-review=, =gh-slack=, =gh-storage=, and
=gh-throttle=. =make install= installs all of them.

** ascii-art

The implemented command is =box-renderer=:

#+BEGIN_SRC bash
bazel build //devtools/ascii-art/cmd/box-renderer
#+END_SRC

=gantt-chart= and =graph-viz= are planned. They have no build target.
