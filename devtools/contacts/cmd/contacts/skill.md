# contacts

`contacts` stores personal contacts, interaction history, and commitments for coding agents to query.

Common commands:
- `contacts init` — initialize store.
- `contacts resolve <handle-or-name> [--json] --reason R` — resolve a contact.
- `contacts history <person> --reason R` — view interaction history.
- `contacts commitments [<person>] [--open]` — list commitments.
