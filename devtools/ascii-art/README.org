#+TITLE: box-renderer
#+DATE: 2026-11-15

* Overview

~box-renderer~ draws a bordered text box made of stacked sections
joined by arrows, for a comment, a README, or a commit message.
Give it sections with ~--section~, or pipe text on stdin.
A sample box is in the Quick start below.

The default frame uses Unicode box-drawing characters.
~--border ascii~ switches the frame to ~+~, ~-~ and ~|~.
The arrow between sections stays ~│~ and ~▼~ until you change
~--connector~. Add ~--prefix~ (for example ~// ~) to paste the box
into a Go or C comment.

* Install

#+BEGIN_SRC bash
go install github.com/jaeyeom/experimental/devtools/ascii-art/cmd/box-renderer@latest
#+END_SRC

From this repo, ~bazel build //devtools/ascii-art/cmd/box-renderer~
builds the same program.

* Quick start

#+BEGIN_SRC bash
box-renderer --section Request --section Auth --section Handler
#+END_SRC

#+BEGIN_EXAMPLE
┌───────────┐
│  Request  │
│     │     │
│     ▼     │
│  Auth     │
│     │     │
│     ▼     │
│  Handler  │
└───────────┘
#+END_EXAMPLE

A vertical bar inside one ~--section~ value starts a new line in
that section.

#+BEGIN_SRC bash
box-renderer --section 'Request|the first step' --section Handler
#+END_SRC

#+BEGIN_EXAMPLE
┌──────────────────┐
│  Request         │
│  the first step  │
│        │         │
│        ▼         │
│  Handler         │
└──────────────────┘
#+END_EXAMPLE

* Options

| Flag        | Default  | Meaning                                                         |
|-------------+----------+-----------------------------------------------------------------|
| --section   | none     | Section text. A vertical bar separates lines. Repeat the flag.  |
| --connector | │ then ▼ | Characters between sections. A vertical bar splits those lines. |
| --border    | single   | single, double, rounded, or ascii                               |
| --padding   | 2        | Spaces inside the left and right edges                          |
| --width     | 0        | Box width. ~0 = auto~ sizes the box to the text.                |
| --prefix    | empty    | Text placed before every output line                            |

The default ~--prefix~ is empty (~""~).
The default ~--connector~ value is ~│|▼~: a vertical bar, then an arrow.
~--border~ accepts ~single~, ~double~, ~rounded~, and ~ascii~.

This is the same box with a plain-ASCII frame, an ASCII arrow, and a
comment prefix.

#+BEGIN_SRC bash
box-renderer --border ascii --prefix '# ' --connector '+|v' --section Request --section Handler
#+END_SRC

#+BEGIN_EXAMPLE
# +-----------+
# |  Request  |
# |     +     |
# |     v     |
# |  Handler  |
# +-----------+
#+END_EXAMPLE

* Reading from stdin

With no ~--section~ flags, ~box-renderer~ reads stdin. A line that is
only ~---~ starts a new section. Other newlines stay inside the
current section.

#+BEGIN_SRC bash
printf '%s\n' Request 'line two' --- Handler | box-renderer
#+END_SRC

#+BEGIN_EXAMPLE
┌────────────┐
│  Request   │
│  line two  │
│     │      │
│     ▼      │
│  Handler   │
└────────────┘
#+END_EXAMPLE
