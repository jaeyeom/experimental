These ~--json~ shapes are the stable contract other tools parse.
The text commands are in [[file:../README.org][the agentbus guide]].

* list --json

~list --json~ prints a JSON array with one object per registered name,
or ~[]~ when none are. Each object has these fields, which are stable:

| Field | Value |
|-------+-------|
| ~name~ | The registered name. |
| ~when~ | Its ~--when~ text. |
| ~liveness~ | ~alive~, ~dead~, ~hibernated~, or ~unknown~. |
| ~liveness_age~ | Seconds since ~liveness~ was observed, or ~null~ when it never was. |
| ~transport~ | The adapter that reaches it, such as ~herdr~. |
| ~handle~ | The holder's raw handle. |

~liveness~ folds the text words: ~alive~ and ~blocked~ are ~alive~,
~gone~ is ~dead~, ~hibernated~ stays ~hibernated~ (see
[[file:hibernate.org][Hibernate idle agents]]), and ~unreachable~ is ~unknown~. When the daemon cannot
be reached, ~list --json~ prints nothing on stdout and exits non-zero.

~list~ answers from the daemon's cached liveness and makes no adapter
calls, so it returns at once. The cache is kept from the periodic
inventory snapshots, delivery results, and probes. When the last full
probe is older than ~list_liveness_max_age~ (default ~15s~), a ~list~
starts one background probe of every name, and only one runs at a time;
that ~list~ still answers from the cache. A machine that cannot be
reached marks only its own names ~unreachable~. ~list --fresh~ (also
with ~--json~) probes every name now, as ~list~ did before, and refreshes
the cache. ~search~ and ~register~ claims keep their own liveness checks.

* lease status --json

~status --json~ prints this shape, which other tools read and which
stays stable. ~--all~ prints an array of them. ~state~ is ~free~,
~held~, ~paused~, ~releasing~, or ~needs-adopt~. ~holder~ is absent
when the checkout is free. ~name~ is the registered name, or empty.

#+BEGIN_SRC json
{"checkout": "local:/home/u/src/repo", "state": "held",
 "holder": {"handle": "...", "name": "...", "since": "RFC3339",
            "deadline": "RFC3339", "why": "..."},
 "queue": [{"handle": "...", "name": "...", "urgent": false,
            "for": "40m", "since": "RFC3339"}],
 "backup_ref": "... (only when there is one)",
 "with": ["... (panes the user's pause is shared with, when any)"]}
#+END_SRC

* mem --json

~--json~ prints one object with ~agents~, ~total_rss_bytes~,
~available_bytes~, ~machine~ (the ~machine~ config label, else the host
name), ~states~ (count by state), ~notes~, and ~hibernate_policy~ (~mode~,
and unless it is ~off~, ~below_bytes~, ~target_bytes~, and
~min_idle_seconds~). Each agent has ~pane~,
~tab~, ~handle~, ~names~, ~state~, ~idle_since~ (an RFC 3339 time or
~unknown~), with a time also ~idle_seconds~ and
~idle_since_lower_bound: true~ for an at-least time, ~rss_bytes~, ~jobs~
(each with ~pid~, ~age_seconds~, -1 when unknown, and ~command~),
~leases~ (each with ~checkout~ and ~role~, ~holder~ or ~queued~),
~session~ (herdr's ~agent_session.value~), and ~error~ when its
process-info could not be read. Byte counts are integers;
~available_bytes~ is left out when it cannot be read.

* hibernate --json

Output is one line per agent: ~hibernated <name> (<rss> freed)~,
~refused <name>: <reasons>~, ~failed <name>: <reason>~, or with
~--dry-run~, ~would hibernate <name> (<rss>)~. ~--dry-run~ writes no
record, sends no input, and logs nothing. Flags may come before or
after the names; ~--~ ends them. ~--json~ prints an array of
objects with ~name~, ~handle~, ~pane~, ~outcome~ (~hibernated~,
~refused~, ~would-hibernate~, or ~failed~), ~reasons~, ~rss_bytes~, and
~warning~. The daemon logs ~agent_hibernated~ and
~agent_hibernate_refused~ (detail ~stop-failed~ for a stop that timed
out). The exit status is 1 when a stop failed or a named agent was
refused; refusals under ~--idle-over~ exit 0.

* send and reply --json

~send --json~ and ~reply --json~ print one object with ~id~, ~state~,
and, only when the accept was a retry of the same client id, ~duplicate~
set to ~true~. Text output stays ~<id> <state>~.

* held --json

~held --json~ prints a JSON array (or ~[]~ when empty) of objects with:

| Field | Value |
|-------+-------|
| ~id~          | Message id.                                                        |
| ~from~        | Sender display name or handle.                                     |
| ~to~          | Recipient name or handle.                                          |
| ~reason~      | Stored hold reason text.                                           |
| ~reason_code~ | Stable reason code (~draft~, ~ordering~, ~login-expired~, etc.).   |
| ~held_detail~ | Optional match detail when a hold recorded one (omitted if empty). |
| ~held_since~  | RFC3339 UTC timestamp when the hold began.                         |
| ~age~         | Human-readable hold duration.                                      |
| ~age_seconds~ | Integer seconds since ~held_since~.                                |

* asks --json

~asks --json~ prints a JSON array (or ~[]~ when empty) of objects with:

| Field | Value |
|-------+-------|
| ~id~ | Message id. |
| ~from~ | Sender display name or handle. |
| ~to~ | Recipient name or handle. |
| ~sent~ | RFC3339 UTC timestamp when sent. |
| ~age~ | Human-readable age since ~sent~. |
| ~age_seconds~ | Integer seconds since ~sent~. |
| ~first_line~ | First non-empty line of the message body. |
| ~rule~ | Matched rule: ~explicit~, ~question-mark~, or ~sender-skill~. |

* dialogs --json

~dialogs --json~ prints a JSON array (or ~[]~ when empty) of objects with:

| Field | Value |
|-------+-------|
| ~pane~ | Pane id, such as ~w1:p2~. |
| ~agent_name~ | First registered bus name, or ~""~ if unregistered. |
| ~handle~ | Raw handle when present. |
| ~machine~ | Machine name, such as ~local~ or ~linux2~. |
| ~rule~ | Built-in or configured rule name that matched. |
| ~text~ | Single-line truncated matched text. |
